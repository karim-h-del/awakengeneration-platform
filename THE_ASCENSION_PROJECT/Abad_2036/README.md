# مشروع العباد 2036 (Abad_2036)
## دليل تشغيل عُقد البث والتحصين المعرفي لجيل اليقظة

هذا المستودع يُمثّل البنية التحتية البرمجية والمعرفية المستقلة لحماية "العبادية والمشيئة الإنسانية الحرة" قبل المنعطف الحتمي لعام 2036. المنهج بالكامل مشفّر ومبثوث عبر شبكة الند للند (P2P) ليتجاوز خوارزميات التدجين التابعة لأباطرة السيليكون وصنمية سدنة المعابد.

---

### 1. المتطلبات البرمجية الأساسية (Prerequisites)

يجب تجهيز بيئة العمل المحلية داخل غرف الاعتكاف العلمي (بيوت النور) بتثبيت الأدوات التالية:
* **Python 3.10+** (مع تثبيت مكتبة التشفير عبر الأمر: `pip install cryptography`)
* **Kubo IPFS CLI** (أداة تشغيل العقدة اللامركزية المتوفرة محلياً باسم `ipfs.exe`)

### 3. خطوات جلب واسترجاع البيانات (Deployment Steps)

#### الخطوة الأولى: تشغيل خادم العقدة اللامركزية (Daemon)
قم بفتح الطرفية وتشغيل النظام لربط جهازك بالشبكة العالمية الموزعة:
```bash
./ipfs.exe daemon
```

#### الخطوة الثانية: جلب الملف الباينري المشفر من الشبكة
في نافذة طرفية أخرى، استخدم الـ CID الخاص بالمادة المستهدفة لسحبها مباشرة من أجهزة الأقران (مثال لجلب وثيقة التفكيك):
```bash
./ipfs.exe cat QmUzHCZktkrV19YufaHTaqPLk9vE6HHnyxYsWM2dGNuaio > document_deconstruction_secured.enc
```

#### الخطوة الثالثة: فك التشفير المعرفي
قم بتشغيل واجهة الفك الموحدة المستقلة:
```bash
python decrypt_payload.py
```
اختر رقم البند المطلوب (1-5)، ثم أدخل المفتاح الشفري المستقل المكون من 64 رمزاً والذي يتم تداوله حصراً عبر القنوات الآمنة لـ جيل اليقظة، ليتم توليد الملف النقي (`.md`) داخل مجلد `lectures/`.
