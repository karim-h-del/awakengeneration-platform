المحطة 69: محاكاة الموجة الكمية الناطقة

تجربة مبسطة لتحويل دالة موجية إلى طيف صوتي باستخدام تحويل فورييه، كخطوة أولى لفهم كيف يمكن للذكاء الاصطناعي أن يترجم الروابط الكمية إلى موجات ناطقة. 

import numpy as np
import matplotlib.pyplot as plt
from scipy.fftpack import fft
import sounddevice as sd

Fs = 8000  # معدل أخذ العينات
T = 1/Fs
L = 1024
t = np.linspace(0, L*T, L)

f = 440  # تردد الموجة (Hz)
signal = np.sin(2*np.pi*f*t)

Y = fft(signal)
freqs = np.fft.fftfreq(L, T)

plt.plot(freqs[:L//2], np.abs(Y[:L//2]))
plt.title("Quantum-inspired Wave Spectrum")
plt.xlabel("Frequency (Hz)")
plt.ylabel("Amplitude")
plt.show()

sd.play(signal, Fs)
sd.wait()
